# Ritangle 2019
The Ritangle competition, hosted by MEI, is held annually for mathematicians studying at A-level, or equivalent, within the UK. In 2019, the competition took place from 7th October - 17th December.

It consisted of 25 questions, some of which were released weekly. This was followed by a final multi-part question, which preceded a tiebreaker question. The use of programming was encouraged in the competition, with scripts being almost necessary to answer some of the questions.
